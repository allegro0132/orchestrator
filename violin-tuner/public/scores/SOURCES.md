# ARCO bundled score editions

These are editable MusicXML practice editions of openly licensed or public-domain scores from the [Mutopia Project](https://www.mutopiaproject.org/). Source editions and practice adaptations are credited below. Each file also embeds attribution, its source URL, license URL and modification description in MusicXML identification metadata. Downloads are available in the app.

The levels are ARCO editorial estimates for the **included edition at its suggested slow tempo**, based on pitch range, rhythm and string crossings. They are not examination grades. Excerpts and simplified melodies do not reproduce the full original arrangement. All editions follow written order once, without repeats. Instrumental technique, phrasing and bowing should be checked with a teacher.

## Reproducible source files

Original LilyPond files (including original attribution and license notices) and the four MIDI inputs are retained under `violin-tuner/scripts/score-sources/` in the repository. They were retrieved from the download links of the above Mutopia pages on 2026-10-22. `rieding-header.ly` retains the shared source header; `rieding-source.ly` retains the original three-movement violin part. The retained MIDI is the first movement's `rieding_opus_35_violin_score.mid`, extracted from the site's MIDI ZIP. The additional three source editions were retrieved on 2026-10-22. `lullaby-source.ly` is the original voice/piano `Wiegenlied.ly` from the LilyPond ZIP; Old 100th and Gavotte retain their original source headers. Other MIDI files are unmodified downloads, renamed for clarity.

The script `violin-tuner/scripts/build-score-library.mjs` contains the source-derived monophonic transcriptions for Ode to Joy, Amazing Grace, Minuet, Old 100th and Brahms’ Lullaby, and extracts the documented MIDI passages for the other pieces. Rebuild from the app directory with:

```sh
node scripts/build-score-library.mjs
```

No external network access or external music software is required to rebuild. Import tests check all generated assets, pitches, timing, pickup measures, excerpt rests, and tied duration.
